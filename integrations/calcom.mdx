Dimedove's Cal.com integration lets your AI agents help visitors book meetings without leaving the chat. Share a Cal.com link for a quick setup, or connect your account so the agent can check availability, book, and reschedule meetings directly.

## Integration features

### Scheduling modes

- **Event link**: the agent shares a link to a specific Cal.com event type, and the visitor books on your Cal.com page.
- **Live calendar**: the agent reads your real availability and manages bookings inside the conversation.

### Agent actions

In live calendar mode, you choose which actions your agent can perform:

- **Check availability**: present real open time slots from your Cal.com calendar.
- **Book a meeting**: confirm the visitor's details and schedule the appointment.
- **Reschedule a meeting**: move an existing meeting to a new time the visitor chooses.

### Key capabilities

- **Multiple event types**: offer different meeting types and tell the agent when to use each one.
- **Permission control**: enable availability, booking, and rescheduling independently per task.
- **Unified inbox**: every conversation appears in your Dimedove dashboard alongside all other channels, and any bookings made during a conversation are tracked right within it.

## Getting connected

To connect your Cal.com account:

1. Navigate to your agent's **Tasks** and add a **Calendar** task.
2. Select **Cal.com** as the provider.
3. Choose **event link** mode and paste a booking URL, or choose **live calendar** mode and enter your Cal.com API key.
4. Add the event type(s) visitors can book, using each event type's ID, with a label and an optional condition.
5. Choose which actions the agent can perform, then save and test.

<Info>
  Calendar tasks are part of Dimedove's agent task capabilities. See the [Calendar task documentation](/platform/agents/tasks/calendar) for full setup details.
</Info>
